# 演示视频脚本（3-5 分钟）

目标：让面试官 / HR 快速理解项目价值。语言：中文，节奏快，重点展示 AI 能力。

## 分段脚本

### 0:00 - 开场（15 秒）
> 这是 Notebook-Evo，一个隐私优先、多模型的 AI 知识工作台。
> 它管理你的研究资料，用 AI 问答、检索与内容生成构建知识工作流。

**画面**：项目主页 + 演示笔记本列表

### 0:15 - 知识摄取（30 秒）
> 上传一份 PDF 到演示笔记本，系统自动完成分块与向量化。

**画面**：拖拽上传 PDF → 显示处理进度 → 来源列表出现

### 0:45 - RAG 问答（45 秒）
> 问一个关于文档内容的问题，AI 基于检索到的上下文回答，并附引用来源。

**画面**：聊天界面提问 → 流式回答 → 展开引用

### 1:30 - 混合检索调试（45 秒）
> 打开混合检索调试台，可以看到同一个查询同时命中向量检索和全文检索，
> 通过 RRF 融合出最终结果——这是生产级 RAG 的标准做法。

**画面**：搜索页 → 输入查询 → 展示双路命中 + RRF 分数

### 2:15 - RAG 评估中心（45 秒）
> 一键运行评估，用 RAGAS 四维指标（忠实度、相关性、精确度、召回率）
> 量化回答质量，生成可导出报告。

**画面**：评估中心 → 运行评估 → 指标条形图 + 逐题明细

### 3:00 - 知识图谱问答（40 秒）
> 图谱展示文档中的实体关系，可以用自然语言提问，
> AI 会沿着图谱路径推理并结合文档回答。

**画面**：知识图谱可视化 → 提问 → 图谱路径展示

### 3:40 - Agent 编排 + MCP（40 秒）
> 多智能体系统支持任务编排与持久化；同时知识库能力通过 MCP
> 暴露给任何 AI 客户端，这是 2026 年 AI 工程的核心能力。

**画面**：Agent 页面任务依赖图 → MCP 终端演示工具调用

### 4:20 - 收尾（20 秒）
> 完整架构、CI、Docker 一键部署都在 GitHub 上，欢迎查看。

**画面**：README + GitHub 仓库 + 二维码

## 录制工具建议
- OBS Studio（免费）
- 1080p / 30fps，普通话配音或字幕
- 最后压缩为 720p MP4 便于简历附件

## 注意
- 演示前先跑 `start-demo.bat` 确保数据就绪
- 避免出现真实 API Key
- 录制失败片段可重录，剪辑拼合
