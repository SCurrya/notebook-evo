# 3 分钟演示视频讲解稿

> 录制设备：手机（电脑录屏也可），格式 1080p，时长 3 分钟以内。
> 上传平台：B 站（首选）/ YouTube，把嵌入链接加进 README。
> 风格：像产品经理给老板演示一样，自然流畅。

---

## 时间线（总长 3 分钟）

### 0:00 – 0:20 · 开场（10 秒开场 + 10 秒自我介绍）

> **画面**：录屏打开 `localhost:8889` 主页（截图工具或录屏软件）。

**旁白**（自然语速）：
> "这是一个我独立做的 AI 知识工作台，叫 Notebook-Evo。它是 [Open Notebook](https://github.com/lfnovo/open-notebook) 的深度增强版本。
>
> 简单说，就是你可以**把研究资料丢进去**，然后**跟你的资料对话**，支持混合检索、知识图谱、RAG 评估，还能手机电脑同步。
>
> 全程本地，数据不出你的电脑。"

### 0:20 – 0:50 · 上传文档 + 检索（30 秒）

> **画面**：切换到 Sources 标签，点击"上传"，随便拖一个 PDF 进演示笔记本。等待几秒出现"已嵌入"。

**旁白**：
> "演示一下核心流程：上传一个 PDF——这是之前准备的 AI Agent 综述——系统自动切片、做嵌入、入库。
>
> 然后切到搜索，输入 'AI Agent'，看——返回了 3 个结果，带原文片段和引用。这就是混合检索：BM25 + 向量 + RRF 融合。"

### 0:50 – 1:30 · RAG 问答（40 秒）

> **画面**：切到 Ask（beta）标签，输入 "什么是 AI Agent？用一句话"。

**旁白**：
> "现在试试 RAG 问答——这是核心 AI 功能。
>
> 提问 '什么是 AI Agent'——3 秒后系统给出答案，**带具体引用来源**。
>
> 这是 LangGraph 编排的三阶段流程：策略 → 多个候选答案 → 最终总结。还自动评估 Faithfulness 等四个 RAGAS 指标。"

### 1:30 – 2:00 · 知识图谱（30 秒）

> **画面**：点击笔记本的"图谱"标签。展示实体和关系的可视化。

**旁白**：
> "再看看知识图谱——系统能从文档里自动提取实体和关系，建图谱。这里我们看到 21 个实体、19 条关系。
>
> 这个图能直接喂给问答做 GraphRAG 推理，把离散检索变成结构化推理。"

### 2:00 – 2:30 · 手机同步（30 秒）

> **画面**：拿出手机，访问公网 URL，展示手机端 UI。截图面板布局一致。

**旁白**：
> "手机端访问——同一份数据，自动同步。我们用 Tailscale 内网穿透 + PWA，手机上能像原生 App 一样全屏使用。
>
> 你看到的是演示环境跑在另一个 4G 网络下，手机扫码或链接直接访问。"

### 2:30 – 3:00 · 技术亮点总结（30 秒）

> **画面**：切到 GitHub 仓库页面（录屏切换）。

**旁白**：
> "最后说技术亮点——这个项目有 **360+ 单元测试**、**CI 自动跑**，跨 Provider 模型降级（xcode.best、SenseNova、OpenRouter 任何一个挂了自动切），还有完整的 **SSRF 防护、SQL 注入修复、密码恒时认证**等安全工程。
>
> 仓库 README 有完整的架构图、CHANGELOG 和技术决策说明。
>
> 欢迎 star、fork、提 issue，谢谢！"

## 录制技巧

1. **先录 5 分钟原始素材**，剪辑到 3 分钟
2. **每个画面之前录 1 秒静态帧**（避免突然切换）
3. **字幕一定要加**（静音自动播放很常见）
4. **结尾留 5 秒黑屏**（避免截断感）
5. **背景音乐用轻 BGM**（音量 < 旁白 1/4）
